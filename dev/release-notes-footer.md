
## Install
1. Download the `.zip` below (do not unzip it).
2. Put it in your Factorio `mods` folder:
   - **Windows:** `%APPDATA%\Factorio\mods`
   - **macOS:** `~/Library/Application Support/factorio/mods`
   - **Linux:** `~/.factorio/mods`
3. Launch Factorio and enable it in **Mods**. It depends on **flib** — accept Factorio's prompt to download it.
